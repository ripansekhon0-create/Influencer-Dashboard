 Starbucks Influencer Analytics Dashboard

Project Overview

The **Starbucks Influencer Analytics Dashboard** is an interactive Power BI dashboard designed to analyze influencer performance and social media engagement for Starbucks.

The dashboard provides a clear view of influencer reach, engagement rates, followers, likes, views, comments, content platforms, and estimated sales. It helps identify high-performing influencers and understand which platforms and content types generate better engagement and business results.

---

## Objectives

- Analyze influencer performance and engagement.
- Compare followers, likes, views, and comments.
- Identify high-performing influencers.
- Analyze engagement rates across influencers.
- Compare content performance across social media platforms.
- Understand the relationship between estimated profit and sales.
- Support data-driven influencer marketing decisions.

## Tools & Technologies

- **Microsoft Excel** – Data preparation and organization
- **Power BI** – Data analysis and interactive dashboard
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **GitHub** – Project documentation and version management

## Dataset

The dataset contains influencer marketing information related to Starbucks.

### Main Data Fields

- Influencer ID
- Influencer Name
- Followers
- Likes
- Shares
- Comments
- Views
- Engagement Rate
- Social Media Platform
- Content Type
- Estimated Sales
- Estimated Profit
- Region

##  Data Preparation

The data was prepared before creating the dashboard by:

1. Checking the dataset for missing or incorrect values.
2. Cleaning and organizing the columns.
3. Checking data types and numerical fields.
4. Removing unnecessary inconsistencies.
5. Creating calculated measures for analysis.
6. Connecting the prepared data to Power BI.

##  Dashboard Features

The dashboard contains KPI cards and interactive visualizations for analyzing influencer marketing performance.

### Key KPIs

- **Average Engagement:** 78.40K
- **Number of Influencers:** 5
- **Total Shares:** 100K
- **Total Views:** 10M
- **Total Comments:** 14K

### Visualizations

- Count of Followers by Influencer and Shares
- Engagement Rate by Followers and Likes
- Engagement Rate by Influencer
- Count of Likes by Influencer
- Estimated Sales by Content Type
- Estimated Sales by Estimated Profit
- Count of Content Type by Platform
- Region and Influencer slicers for interactive filtering

## Key Insights

- The dashboard helps identify influencers with comparatively higher engagement rates.
- Follower size and engagement can be compared to evaluate influencer effectiveness.
- Instagram and YouTube show strong representation in the analyzed content.
- Content type can be evaluated based on its estimated sales contribution.
- Estimated sales and profit can be compared to understand marketing performance.
- Interactive filters allow users to analyze results by region and individual influencer.

##  Business Value

The dashboard can help Starbucks make better influencer marketing decisions by identifying effective influencers, understanding audience engagement, and evaluating content performance.

It provides a visual and data-driven approach to improve influencer selection, campaign planning, and marketing performance.
